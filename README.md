# UltiRace

Short, chaotic kart-style multiplayer racer for iOS. Godot 4.7.2 client, authoritative Go server.

- Design and architecture: [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md)
- Status: [`docs/PROGRESS.md`](docs/PROGRESS.md), milestones: [`docs/MILESTONES.md`](docs/MILESTONES.md)
- Toolchain and commands: [`docs/TOOLCHAIN.md`](docs/TOOLCHAIN.md)

```bash
make doctor     # check the toolchain
make test       # Go + Godot tests
make server     # dev server on 127.0.0.1:8090
make ios-run    # build, install and launch on the connected iPhone
make help       # all targets
```
